# Sahi Scan

Sahi Scan is a smart food-scanning application designed to help users understand packaged food products and make informed decisions about what they consume.

The application retrieves product information, analyses nutritional details, and helps users evaluate food products based on their nutritional preferences.

## Features

- **Food Product Scanning:** Scan packaged food products to retrieve product information.
- **Product Information:** Retrieve food details from an Excel-based product database.
- **Nutrition Analysis:** Understand nutritional values such as sugar, sodium, and other important nutrients.
- **Ingredient Analysis:** Help users understand the ingredients present in packaged food.
- **Food Logging:** Record scanned food products for future reference.
- **Scan History:** Maintain a history of previously scanned products.
- **Product Images:** Display product images alongside their nutritional information.
- **Food Recommendations:** Help users make better food choices based on nutritional information.

## Technologies Used

- Python
- React
- JavaScript
- HTML
- CSS
- Excel-based product database

## Project Workflow

1. User scans a packaged food product.
2. The application identifies the product.
3. Product information is retrieved from the available database.
4. Nutritional information and ingredients are analysed.
5. The results are displayed to the user.
6. Food information can be recorded for future reference.
